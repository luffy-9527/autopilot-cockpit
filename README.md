# Autopilot Cockpit 智能座舱自动驾驶数字孪生仿真系统

基于 **React 19 + Three.js + Tailwind CSS + Vite** 构建的现代化智能汽车车载中控 / 自动驾驶（ADAS）高精度数字孪生 3D 仿真系统。

---

## 🌟 核心特性

- 🏎️ **宝马 M4 Competition (G82) 官方原厂级 3D 数字孪生**：
  - 完整呈现双门轿跑流线、竖直无框大双肾中网、M 专属空气动力学碳纤套件与双边四出真圆排气；
  - 官方 2026 首发经典**布鲁克林金属灰 (Brooklyn Grey Metallic)** 珍珠高光清漆；
  - **轮胎车速动态联动**：车轮与低扁平比锻造轮毂依据真实行驶车速（km/h $\to$ rad/s）原位同心飞驰旋转，M 运动蓝色卡钳稳固静止咬合。
- ☀️ **全天候日夜光照与感知渲染**：
  - 支持白天（日光晴空、半球漫射天光）与夜间（冷色月光、大灯地面铺光、斜射空气柔光锥、车尾红色光晕、一体连体双挑臂 LED 路灯）平滑无缝切换；
  - 道路标线、周围交通车流（重型厢式货车、轿车）动态位移。
- 🎥 **四维全景视角自由切换**：
  - **跟车视角 (Chase)**：车辆居中舒展，车尾四出排气与前照光毯尽收眼底；
  - **自由视角 (Free 360°)**：支持鼠标拖拽 360 度环视欣赏整车工业美感；
  - **俯视视角 (Top-down BEV)**：鸟瞰车道规划路径、周围交通参与者与鸟瞰雷达网；
  - **驾驶视角 (Cockpit)**：第一人称座舱开阔视野，无穿模无遮挡。
- 📊 **车机级 ADAS HUD 交互界面**：
  - 顶部导航路线规划与变道状态；
  - 左侧实时自动驾驶决策日志流 (Decision Log)；
  - 左下角数字车速与能量进度仪表盘（支持 60 / 80 / 100 / 120 km/h 触控平滑过渡）；
  - 右侧纵向控制 (ACC/AEB)、续航能耗、感知系统传感器状态实时监控面板。

---

## 🛠️ 技术栈

- **前端框架**：React 19, TypeScript
- **3D 渲染引擎**：Three.js, GLTFLoader
- **样式与构建**：Tailwind CSS v4, Vite 6
- **包管理器**：pnpm

---

## 🚀 快速启动

```bash
# 1. 克隆项目
git clone https://github.com/luffy-9527/autopilot-cockpit.git
cd autopilot-cockpit

# 2. 安装依赖
pnpm install

# 3. 启动本地开发服务
pnpm dev
```

启动后在浏览器打开：`http://localhost:5173/`
